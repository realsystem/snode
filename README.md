# SNODE

Low-cost DIY soil-moisture monitoring for a 600-tree off-grid farm in a
cold-desert climate. One SNODE (soil node) reads a cluster of capacitive probes,
runs on a small battery and solar panel, and reports to Home Assistant over ESP-NOW.
HA makes all irrigation decisions.

Status: design interview in progress (no hardware or firmware yet).

Start with [`CLAUDE.md`](CLAUDE.md) for terms and rules, then [`docs/`](docs/).
